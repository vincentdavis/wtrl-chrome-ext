WTRL Team Report — Settings

Coalition team app

Optional. Set an API key here to push reports straight to app.coalitionracing.com instead of downloading them. The key is stored in extension storage and is only ever read by the background worker — it is never exposed to wtrl.racing.

Collection

Each team is read one at a time. Transient failures (timeouts, rate limits, server errors) are retried up to three times with a growing delay, and the whole run slows down when WTRL shows strain. Raise the timeout if you manage many teams or your connection is slow.

WTRL endpoint

Learned automatically the first time you build a report — the extension watches the request the site makes when a team panel is opened, then reuses it for the remaining teams. Only change this if you know the URL.

Data

The most recent report is kept locally so the popup can re-download it.
